### Comments (non-blocking)

- **The equal-depth-disagreement raise (366–370) is unreachable via `discover_catalogue`, and untested.** `source_id` derives from `yaml_path.parent`, and two distinct `source.yaml` paths cannot share a parent — so distinct sources always yield distinct `standardized_dir`s, and two *different* dirs can never both contain the same path. An equal-depth collision therefore requires same `source_id` + same slug ⇒ same file ⇒ `load_source`'s slug-agreement already raised. Fine as defence-in-depth (it fires for hand-built `Source` objects), but don't count it as coverage.
- **`test_real_catalogue_default_pool_is_seventeen` pins the pool *count*, not its membership.** Two compensating `canonical_language` errors would pass. Asserting the sorted set of 17 `text_key`s would make the anchor exact, and would double as the readable statement of what the corpus is. Cheap and worth it, since this is the one test standing between a typo and a silently different benchmark.
- **No vocabulary check on `canonical_language`.** `canonical_language: ara` against `language: ar` silently *shrinks* the pool rather than failing — the one place in this phase where a mistake is quiet instead of loud. Mitigated by the count assertion above and by Phase 2's manifest exclusion reasons, so I'm not asking for a change; just noting it's the residual soft spot in an otherwise fail-fast contract.
- **`requested_as` elements are neither stripped nor deduped.** `"  KJV "` passes `x.strip()` truthiness but is stored unstripped and would render into a prompt verbatim; a duplicate entry would skew Phase 2's seeded *uniform* choice. Consistent with how the existing string fields behave, and no committed value is affected, so optional — but Phase 2 is where it would surface.

The real-data integration anchor is simply gone. The Talmud Aramaic target emits many documents sharing one `(work, version, language)` and is a larger real multi-shard case — if you want that anchor back, it's the natural replacement, but it's out of this phase's scope.
