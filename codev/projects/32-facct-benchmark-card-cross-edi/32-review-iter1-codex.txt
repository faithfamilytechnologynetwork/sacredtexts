KEY_ISSUES:
- `edition_index.write_export()` claims both-or-neither behavior, but lines 219–220 replace the JSONL before the manifest without rollback. If the second replacement fails, consumers receive a new index with a stale or missing manifest. Use collision-safe temporary files plus backup/rollback logic, and add a failure-injection test for the second replacement.
- `build_facct()` copies the run manifest’s `corpus_hash` while calculating the counterfactual from the current raw corpus without validating or recording that corpus. They already differ: the run records `5ae493e7e249575c`, while `load_edition_documents()` currently hashes to `08f1bc8c010cfbe6`. Thus raw-corpus changes can silently alter `other_edition` results while the card advertises only the run hash. Validate compatibility or record/pin the actual edition-index corpus hash, with a regression test.
