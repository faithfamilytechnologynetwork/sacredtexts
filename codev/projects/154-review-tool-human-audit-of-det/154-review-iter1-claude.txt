## What's Genuinely Strong

**The cross-language byte contract is correct, not just claimed.** `_js_number` guards exactly where Python and JS shortest-form float output diverge: integral floats are emitted as ints (matching JS for ≥1e16 where Python would use exponent form), ≥1e21 raises, and `<1e-4` raises — Python switches to exponent notation at 1e-4 while JS waits until 1e-6, so the guard is correct and deliberately conservative. Non-integral floats above 2^53 can't exist, so that gap is unreachable. I confirmed no metric in the real sample lands in the risky range (smallest nonzero: 0.0104). The shared `fixtures/review_gold_set.jsonl` pins **both** writers, which is the only thing that makes this a test rather than a hope.

**The session-counter guard is applied uniformly.** Every async path in `review.ts` — load, list, save, delete, init, sample fetch — captures `started = session` and drops its result on reset. That closes the reviewer-A-draft-lands-in-reviewer-B's-state leak properly rather than at one call site.

**Path traversal is actually safe.** `serveStatic` decodes via `tryDecodeURI` *then* rejects `.`/`..` segments, doubled slashes and backslashes, so `/%2e%2e/...` is caught. `mountViewer` is correctly mounted after the API routes, and `isApiPath`/`isAssetPath` keep `/api/*` and missing bundles off the SPA fallback.

One nice detail: in `signup`, `hashPassword` runs *after* the invite-code check, and `login` only calls `verifyPassword` for an existing email. That keeps unauthenticated argon2 CPU amplification small — a real consideration now that the service is public.

1. **`SameSite=None` deserves promotion from "deferred cleanup" to near-term.** It's already in your follow-ups, but there's an extra reason now that it's hosted: on a shared parent domain like `*.up.railway.app`, a sibling service could set a `Domain=.up.railway.app` cookie and defeat the double-submit check by cookie-tossing. Whether that's reachable depends on `up.railway.app` being Public-Suffix-List registered — worth confirming rather than assuming. Everything is same-origin now, so `Lax` is a one-line change that closes it structurally.
