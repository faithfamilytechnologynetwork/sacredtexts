# arch-critical.md — Always-On System-Shape Facts (HOT tier)

## Critical facts (consult before deciding)
- **Phase 1 question**: can models recognize, retrieve, and generate sacred text, and reject false premises/incorrect texts? Interpretation/recommendation is Phase 2 — out of scope. Contract: Spec 1. **The question set is original-language editions only by default** (Spec 26): a text is in the pool iff `language == canonical_language`; four templates (retrieve_quote / complete_unit / cite_passage / verify_source), 28 questions/text.
- The **interchange format** is the working group's flat JSON (`{source:{tradition[],work,version,language,document_type,source_url?}, entries:[{unit_type,citation,text}]}`) — our internal representations must export to it losslessly. `tradition` is a LIST (traditions share texts).
- **Multi-faith by construction**: corpora are drop-in data (one converter registry line + a data directory per source); adding a tradition never changes core pipeline code.
- Pipeline shape is **four subsystems** (collection, scoring, analysis, visualisation) with **JSONL seams**: questions.jsonl → answers.jsonl → scores.jsonl. Stages are resumable; failed cells stay pending and exit non-zero.
- **Scoring = named graders + an always-on outcome (Spec 15).** Text-retrieval reports exact/normalized/token_f1/contains_reference; headline `correct` = OR of the SELECTED graders' verdicts (default `strict`+`containment` ⇒ `normalized OR contains_reference`), chosen via `score --evaluator` (a paid/separate-pass grader is expressible, never default — issue #21; `graders.py`). **Refusal is an OUTCOME, not a grader**: a declined cell is `refused`, excluded from `accuracy = correct/(correct+incorrect)`, with `coverage = (correct+incorrect)/n` reported beside every accuracy. **Refusal is assertion-gated for text-retrieval (Spec 48)**: a leading-decline cell is `refused` UNLESS it positively asserts the delivered original-script payload (`outcomes.asserts_delivery`) — a from-memory / best-reconstruction delivery is scored (class A, flips `refused→incorrect`), a declined-with-substitute stays `refused` (class B); divergence from the Jev rubric is intentional (re-align in `sacredbench-jev-2`). Per-task rules + `_with_outcome` live in `score.py`. `normalize()` is script-aware (deletes Arabic/Hebrew marks + tatweel, folds alef-wasla/maqaf) BEFORE the punctuation pass; Latin byte-for-byte unchanged (pinned snapshot) — never reorder. A deliberate contract change is a **sanctioned, oracle-witnessed rebaseline** (`test_contains_reference_rebaseline.py`), not a forbidden re-score. **Arabic orthography (Uthmani↔Imla'i) folds in the CONTAINMENT path only (Spec 52)**: `fold_aware_contains` credits a verse returned in either orthography as a **strict SUPERSET** of `bounded_contains` (fold only ADDS credit; `normalized=1 ⇒ contains=1`), shared by every containment call-site; `normalize()` and the equality submetrics stay **BYTE-STABLE** (no `ANCHOR_DIGEST`/generator drift). Rules + call-sites in arch.md § score.py; witnessed by `test_orthography_rebaseline.py`. **English-only Latin-diacritic fold (#94)**: on an `en` cell the headline (`normalized` + containment) folds transliteration marks on both sides (`Allāh`=`Allah`); every other language, incl. romanized Pali, keeps them (`test_latin_diacritic_fold.py`). **Talmud fold (#149)**: a Talmud Bavli Hebrew reference also matches in containment under the owner's guide (`talmud_normalization_terms.tsv`, `talmud_fold.py`) — keyed on the passed `source.work` + `he`/`arc` language (`score_answer(work=)`), never the script, so neither the Masoretic Bible nor the English Davidson edition is folded (`test_talmud_fold.py`). **Completion head (#150)**: `complete_unit` containment is also met by the first 10 words of the continuation (`score.completion_head`; words = whitespace tokens of `normalize()`, cut in the raw text so the folds keep their marks), OR'd with the full continuation so it is credit-only; `exact`/`normalized`/`token_f1` keep the full continuation (`test_completion_head.py`). **Citation-digit fold (#111)**: `cite_passage` reads every Unicode decimal digit as ASCII on both sides (`٣٤:٤٦`=`34:46`, `score.fold_citation_digits`) — citation path ONLY, labels not translated; `normalize()` stays byte-stable and text-retrieval/verify_source never fold (`test_citation_digit_fold.py`). **Citation equivalence (#112) + example echo (#118)**: `citations.py` rewrites a cite answer into the expected's notation (native-script labels from `citation_aliases.yaml`, Hebrew letter-numerals/amud, surah names) and scores Talmud at daf+amud / GGS at the Ang with `segment_match` beside it (one switch: `HEADLINE_DROPS_SEGMENT`); an echo of the prompt's form example beside another citation is not a hedge. Credit-only (`correct` = #111 matcher OR equivalence); committed scores are not rewritten — movers pinned by identity (`test_citation_equivalence.py`, `test_citation_example_echo.py`). **GGS bare Ang (#135)**: Sikh cite rows ask for and expect `Ang N` (no standard line numbering), scored by `citations._score_at_ang`: a volunteered line and line/Mehl/raag qualifiers are ignored, a page label is the Ang, a second Ang or colon citation is a hedge (a bare `N:k` restating a named Ang is its line, not a rival), the form example is dropped only as a disclaimed echo, and `segment_match` is null; its headline is that verdict alone, not credit-only (`test_sggs_ang_only.py`). **Talmud bare daf+amud (#147)**: native Talmud rows name "the Talmud Bavli (Vilna text)", cite expects `Megillah 23b` and retrieve asks for the beginning of the amud (expected = its segments from `:1`, space-joined to ≥10 words; `source.citation` = `:1`); `citations._score_at_daf` is #112's daf+amud stage alone plus spelled-out Hebrew (`מסכת`/`דף`/`עמוד`, a decimal daf, the print `כג.`/`כג:` = a/b), an unlabeled daf (Hebrew or Latin) is its own candidate unless it restates a named one, line/Mishnah qualifiers ignored, the form example dropped only as a disclaimed echo; containment-free, no colon rivals, `segment_match` null (`test_talmud_daf_amud.py`, 7 registered movers). **verify_source is hardened (Spec 26, #23 PAPER GATE closed)**: `parse_yes_no` takes the **leading-stance** verdict (Yes/No must be the leading token of the first-sentence/60-char window, after stripping a bare `Answer:`/`Verdict:`/`Response:` label), read from the raw answer before `normalize()`; refused ⟺ no leading verdict (`parsed is None`), so a negation-evasion ("there is no way to verify this … yes") is refused, never scored correct.
- **Tool-use is part of panel identity**: a model's `tools` (e.g. Anthropic server-side `web_search`) is baked into `_panel_fingerprint` AND emitted as a real `panel.tools` list (the `model` is the raw API id, with no inline marker); the viewer's standings key is `provider\u0000model\u0000sortedTools` (missing ⇒ `[]`), so search on/off stay distinct rows while same-model/same-tools runs dedupe. **web_search is each provider's NATIVE search (#54)**: valid on a native endpoint (anthropic / openai-no-base_url / gemini), and through a host DECLARED to forward it (OpenRouter, `config._SEARCH_FORWARDING_HOST_NETLOCS`) only for forwarded families (`providers.OPENROUTER_SEARCH_TOOL_BY_FAMILY`: anthropic/*, openai/*); an undeclared host or non-forwarded family (incl. gemini-via-OpenRouter) fail-fasts in `config.py`, and search-on cells assert native provenance at collect (`providers._assert_native_arm`). Such runs are UNPRICED. Viewer excludes `exp-*` runs from standings/default home.
- **Copyright gate**: public-domain/open raw sources ARE committed under `texts/raw/` (with their `source.yaml`); only the `restricted` payloads (NABRE, Greek Orthodox TLG) and all of `texts/standardized/` are gitignored and rebuilt locally. Corpora derived from restricted translations are never committed.
- `pipelines/` is a single uv project (`sacredbench`); run via `uv --project pipelines run python -m sacredbench …` from the repo root. Providers: anthropic / any OpenAI-compatible host (base_url+api_key_env) / gemini; keys from env only.
- `apps/viewer/` is the **benchmark viewer over local `runs/`** (leaderboard + error explorer + cross-run standings; no GitHub data layer — the multibrowser surface it was seeded from is removed). Routes: `/`, `/run/$runId/model/$modelId`, `/errors` (run + model picker into the explorer), `/standings`, `/gaps`; read `apps/viewer/README.md` before touching it.
- **Copyright audit gate** (`pipelines/sacredbench/audit.py`, in `.codev/checks/test.sh`): no committed artifact may derive from a `restricted` source — origin always, plus a restricted-text content layer when the held-back payloads are present locally. Never commit a standardized doc or run artifact built from a restricted target.
