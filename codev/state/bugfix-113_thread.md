# bugfix-113 thread: drop the romanized-Pali prompt arm

## Investigate (2026-11-02)

- Owner decision: drop `buddhism/native/population/prompt-native/`. Its prompts are romanized Pali, and Pali has no native speakers.
- Root cause: `items/for-test/review/build_remaining.py` `question_rows` emits both `ask_english` and `ask_native` for every native set. That includes Buddhism, whose native template `PI` is romanized Pali. `output_files` writes `buddhism/native/<sample>/passages.json` from the `ask_native` group, so that needs a new source. The `ask_english` rows carry the same passages in the same order, so the file is byte-identical.
- No ripple: verify "no" donors are seeded per row, and the donor pool is keyed by (tradition, version, citation) with the `ask_english` retrieve row inserted first. Removing Buddhism's `ask_native` rows should leave every other committed file byte-identical.
- The same arm also exists at `buddhism/native/familiarity/prompt-native/` (not in the run). I asked the architect; the default is to drop both, so the rebuild set goes from 38 to 36 files.
- Counts: `cost.RUNNABLE` goes from 20 to 19, Buddhism from 240 to 120, and a full model from 2,160 to 2,040 cells. Docs are METHODOLOGY.md, README.md, COST.md (generated by cost.py), and the structural line of runs/README.md (no run data). Whether runs/README.md can be edited is also pending with the architect.
- Sequencing: PR #110 (#85) touches the buddhism prompt-native file, METHODOLOGY.md and the rebuild test. I'll implement after it merges and merge origin/main.

## Fix (pre-#110 base)

- #113: `build_remaining.question_rows(native_tmpl=None)` skips the native row. Buddhism passes None and the `PI` templates are gone. passages.json is now written from the `ask_english` group, which gives byte-identical output.
- #116: `_verify_donor` holds the three donor branches. A second pass in `add_verify_negatives` works like this: every row takes its first draw, and the first holder of each text (in citation order) keeps it. Each repeat draws again from its own RNG and skips every text the set's first draws took.
  - My first attempt skipped only the texts already assigned. That cascaded: a redraw took a later row's first draw and moved that row too (29 rows changed instead of 23). Skipping all first draws fixed it.
- The pre-#110 rebuild changes exactly 23 rows: the 21 duplicate prompts from #116's sweep, plus 2 encyclical rows. Those 2 repeat a donor under different prompt wording, because each prompt names its own encyclical, so a sweep by prompt string misses them. The new test checks both prompts and the quoted donor text.
- cost.py had a pre-existing KeyError: `six_traditions` iterated WRITTEN, which includes BoM and encyclicals. That's a one-line fix. COST.md was regenerated: six traditions 1,800, 2,040 on disk.
- Both regression tests fail on the pre-fix tree, checked against a `git archive HEAD` copy in the scratchpad.
